# СКФУ: техническое администрирование

Настольное WPF-приложение для ведения справочников, контингента, учебного процесса, расписания, контроля целостности данных, журнала изменений и резервных копий.

## Возможности

- просмотр недельного расписания по группе, преподавателю или аудитории;
- поиск свободных аудиторий и отображение загрузки корпуса;
- проверка конфликтов при сохранении занятия;
- аудит изменений с откатом операций;
- фильтрация, экспорт и импорт табличных данных;
- резервное копирование и восстановление SQLite.

## Стек

C# 10, WPF, .NET 6/8/10 и Microsoft.Data.Sqlite 8.0.12. Для разработки рекомендуется .NET 10 SDK.

## База данных

По умолчанию файл расположен в `%LocalAppData%\SkfuAdmin\skfu.db`. Для отдельного файла задайте переменную среды `SKFU_DB_PATH`; пример приведён в `.env.example`.

Встроенный набор предназначен для проверки интерфейса и не является выгрузкой из информационных систем университета. Обозначения СКФУ используются в контексте интерфейса.

## Сборка и запуск

```powershell
dotnet build src\SkfuAdmin\SkfuAdmin.csproj -c Release -f net6.0-windows
dotnet build src\SkfuAdmin\SkfuAdmin.csproj -c Release -f net8.0-windows
dotnet build src\SkfuAdmin\SkfuAdmin.csproj -c Release -f net10.0-windows
dotnet run --project src\SkfuAdmin\SkfuAdmin.csproj -f net10.0-windows
```

## Резервные копии

Копии создаются в `%LocalAppData%\SkfuAdmin\backups`. Перед восстановлением используйте команду создания копии в разделе «Система».
